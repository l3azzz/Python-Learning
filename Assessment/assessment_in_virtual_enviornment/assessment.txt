Question 11
q: What is Method Overriding in Python?
a: Method overriding allows a child class to provide a specific implementation of a method that is already provided by its parent class. The method in the child class must have the same name and parameters as the one in the parent class.

Question 12
q: What is Inheritance?
a: Inheritance is a fundamental concept in object-oriented programming where a new class can derive or inherit properties and behaviors (methods) from an existing class. This mechanism promotes code reusability.
